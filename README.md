# Bitcoin Price Forecasting with 6 Machine Learning Models & SHAP
This repository contains a project focused on analyzing and forecasting Bitcoin prices using six different machine learning algorithms, along with model interpretability analysis using SHAP (SHapley Additive exPlanations). The goal is to evaluate the performance of various models in predicting Bitcoin prices and to understand the contribution of each feature to the predictions.

📌 Project Description

In this project, historical Bitcoin price data is utilized to train and test six different machine learning models. SHAP is employed to analyze and explain the influence of each feature on the model's output, providing deeper insights into the factors affecting Bitcoin prices.

🧰 Tools & Technologies
- Python
- Jupyter Notebook
- Pandas, NumPy
- Scikit-learn
- XGBoost
- SHAP
- Matplotlib, Seaborn

📈 Key Results
- Performance evaluation of six machine learning models in forecasting Bitcoin prices.
- Model interpretability analysis using SHAP to understand feature contributions.
- Visualization of prediction results and feature impact on predictions.
